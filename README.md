## 👋 Welcome!
Hey there! This repository tracks the development of **Nerv**, a mock coffee shop website that serves as a bridge between my two worlds: a love for aesthetic design and a fascination with technical systems.
This project is a personal challenge to move from high-level ideation to a **Minimum Viable Product (MVP)**, documenting my growth from a choreographer’s eye for space to a developer’s eye for logic.
> **Note:** This project is currently a work in progress! I am in the final stages of the build.
>

### 🗂️ Project Timeline
✅ **Week 1 – Planning & Research**
 * Brainstorming core concepts and establishing style guides.
 * 
✅ **Week 2 – Wireframing & Sprint Planning**
 * Creating component structures and mapping out development sprints.
 * 
✅ **Week 3 – Structural Foundation & Visual Language**
 * Built the "design-less" HTML structure, navigation, and box dividers.
 * Defined the visual identity: color palettes, typography, and AI-generated imagery tailored to the brand.
 * 
✅ **Week 4 – Dynamic Interactivity & Motion**
 * Implemented JavaScript for sticky navigation and event listeners.
 * Added scrolling effects and 3D logo animations.
 * 
🚧 **Week 5 – The Final Push (In Progress)**
 * Finalizing the 'About', 'Contact', and 'Menu' pages.
 * Building the database and ordering logic using **SQL** and **Python**.
 * Deploying the full-stack web application.
   
### 🚀 Why I’m Building Nerv
Nerv is about **merging dualities**. As I prepare for my journey at WeThinkCode_, I wanted a sandbox where I could test how design components interact with complex systems. It’s a space to practice the "ideation-to-execution" pipeline, ensuring that a beautiful interface is backed by robust, readable code.

### 💡 Highlights & "Aha!" Moments
 * **The Trinity of Web Dev:** Finally seeing the "handshake" between HTML, CSS, and **JavaScript**. I realized that when CSS reached its limit for interactivity, JS was the bridge that brought my buttons to life.
 * **Visual Branding:** Applying my background in theatre and dance to create a clean, intentional UI that feels like a cohesive brand.
 * **Motion Design:** Mastering **CSS Keyframes**. Learning how subtle animations can completely transform the user experience from static to immersive.
 * **AI Integration:** Using GenAI in tandem with my documentation process—writing clear docstrings and compartmentalizing code for better long-term readability.
 * 
### 📉 Lessons Learned (The Lows)
 * **The Planning Gap:** Because I was learning while doing, my sprint planning was a bit reactive. I’ve realized that more rigorous upfront planning would have doubled my productivity.
   
 * **The Responsiveness Struggle:** Designing for a specific desktop resolution only to have it break on other screens was a massive headache. It taught me the "Mobile First" lesson the hard way!
   
### 🎯 Next Steps
Once Nerv is fully served, my next goal is to move into **AI integration**—finding ways to embed machine learning or intelligent automation into the user journey.
