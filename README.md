# README.md
# NERV – Premium Coffee Shop Website

A high-end, modern coffee shop website showcasing a **brutalist-meets-luxury aesthetic**. Built as a portfolio project to demonstrate full-stack web development capabilities, from responsive front-end design to planned back-end integration and AI features.

## Overview

NERV is a conceptual premium coffee brand with a minimalist, tech-forward identity. The website presents a curated selection of specialty coffee drinks and hardware products with an emphasis on clean design, smooth animations, and premium user experience.

**Current Status:** Front-end complete | Back-end and features in development

---

## ✨ Features

### Current (Front-End)
- **Responsive Design** – Mobile-first approach with sticky navigation
- **Hero Video Background** – Full-screen autoplay video with grayscale filter
- **Product Showcase** – 3-column grid layout for seasonal drink selections
- **Hardware Catalog** – Two-column product showcases for coffee machines and accessories
- **Smooth Animations** – Pop-in navigation and hover-lift effects on product cards
- **Sticky Navigation** – Always-accessible main navigation bar
- **Optimized Typography** – Google Fonts integration with monospace and sans-serif hierarchy

### Planned (Roadmap)
- Back-end API with Node.js/Express
- Database (PostgreSQL) for products, orders, and users
- E-commerce functionality (shopping cart, checkout)
- User authentication and account management
- TDD test suite (Jest/Vitest)
- AI-powered product recommendations
- Admin dashboard for inventory management
- Email notifications system

---

## 🛠 Tech Stack

### Current
- **HTML5** – Semantic markup with accessibility best practices
- **CSS3** – Grid layouts, flexbox, animations, responsive design
- **Google Fonts** – Josefin Sans font family

### Planned
- **Back-End:** Node.js, Express.js
- **Database:** PostgreSQL
- **Testing:** Jest / Vitest (TDD approach)
- **AI Integration:** OpenAI API / TensorFlow.js
- **Authentication:** JWT / OAuth
- **Deployment:** Vercel / Netlify (front-end), Heroku / Railway (back-end)

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Text editor (VS Code recommended)
- Git (for version control)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/nerv-coffee.git
   cd nerv-coffee
   ```

2. **Open in browser**
   - Open index.html directly in your browser, or
   - Use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js (http-server)
   npx http-server
   ```

3. **View the site**
   - Navigate to `http://localhost:8000` (or your chosen port)

### File Overview

- **index.html** – Structure of homepage with header, hero video, drinks grid, and product showcases
- **stylesheets.css** – All styling including animations, grid layouts, and responsive breakpoints
- **assets/** – Images and video files for branding and product display
